# TubeVault engineering rules

Never modify source footage or automatically delete source footage or remote resources. Device-original deletion must be user-initiated, limited to the selected originals, explicitly confirmed, and gated on verification of their uploaded backups. Preserve remote videos and archive history during device cleanup. Never log tokens, OAuth responses, session URLs, passwords, or request bodies. All remote changes need explicit privacy. Upload and playlist insertion are separate durable operations. An ambiguous upload must never automatically create a new session. Do not run live uploads unless explicitly authorized. Default localhost, authenticated access, manual queue, private visibility. Keep API, service, database and Google transport separate. Persist transitions and recovery evidence. Run pytest, frontend typecheck/build, Vitest and Playwright when changing their relevant flows. No credentials or footage in Git. Document untested hardware/network behavior honestly.
